📡 UniCsAC API 文档

适用于第三方客户端开发者 · 基于 HTTP + JSON + Session Cookie

🌐 基础信息

统一入口 https://cschat.ccccocccc.cc/rpc/UniCsAC.php

所有接口通过 route 参数指定具体动作，支持 GET / POST。
示例：
GET https://cschat.ccccocccc.cc/rpc/UniCsAC.php?route=user/get_info
POST https://cschat.ccccocccc.cc/rpc/UniCsAC.php?route=auth/login

✅ 认证方式：PHP Session Cookie（自动携带）。登录后服务器下发 Cookie，后续请求必须携带。
✅ 支持 application/json、表单、multipart/form-data。
✅ 未登录返回 401，账号/群组封禁返回 403。

📜 通用响应格式

{
  "success": true,          // 布尔值，业务是否成功
  "message": "操作成功",     // 提示信息
  ...                       // 其他业务字段
}

失败示例

{
  "success": false,
  "message": "未登录"
}

封禁时附带 ban_info 或 room_ban_info 对象。

🔑 认证接口

📌 登录

POST route=auth/login

参数说明
username账号
pwd密码
{
  "success": true,
  "message": "登录成功",
  "user": { "uid": 1, "nickname": "昵称" }
}

📌 注册

POST route=auth/register

参数约束
username3-32位字母数字_@.-
nickname最多16字符
pwd / confirm_pwd至少6位
avatar可选图片文件

成功后自动登录，返回同登录接口。

📌 退出登录

POST route=auth/logout

{"success":true,"message":"已退出登录"}

👤 用户相关

获取用户信息

GET route=user/get_info?uid=123 （不传uid则返回当前用户）

{
  "success": true,
  "user": {
    "uid": 2,
    "nickname": "Alice",
    "avatar": "upload/xxx.jpg",
    "is_friend": true,
    "can_add_friend": false,
    "online_status": "在线",
    ...
  }
}

更新资料

POST route=user/update_profile 根据 action 区分：
· action=nickname → 传 nickname
· action=password → 传 old_password, new_password, confirm_password
· action=avatar → 上传 avatar 文件

好友列表

GET route=user/get_friends → 返回 friends[] 含 unread_count, remark 等。

我的群组列表

GET route=user/get_groups → 返回 groups[] 包含未读数、成员数。

通知相关

GET route=user/get_notifications 获取未读计数。
GET route=user/get_notice_list 获取通知列表。
POST route=user/mark_notice_read (read_all=1 或 notice_id=xx) 标记已读。

我创建的群组

GET route=user/get_created_groups?uid=xxx （可选uid）

🤝 好友关系

发送好友请求

POST route=friend/send_request (to_uid, message可选)

处理请求

POST route=friend/handle_request (request_id, action=agree/refuse)

删除/拉黑好友

POST route=friend/delete_friend 或 route=friend/block_friend 参数 friend_id

恢复好友

POST route=friend/recover_friend (friend_id, direct=1 表示直接恢复，或 message 申请恢复)

修改备注

POST route=friend/update_remark (friend_id, remark)

其他接口：GET friend/get_common_groups , GET friend/get_deleted_notices , GET friend/get_friend_requests

👥 群组接口

创建群组

POST route=group/create (room_name) → 返回 room_id, invite_code

公开群组列表

GET route=group/get_public_list

群组详情

GET route=group/get_group_view_info?room_id=xxx → 返回 room 详情 + 用户状态(is_in_group, is_admin等)

申请/加入群组

POST route=group/apply_join (room_id, 根据 join_type 传 code/answer)

成员列表 & 管理

GET route=group/get_members?room_id=xxx
POST group/mute_member (room_id, target_uid, action=mute/unmute, minutes)
POST group/kick_member
POST group/set_admin (action=set/remove) 仅群主
GET group/get_applications (入群申请)
POST group/handle_apply (apply_id, action=pass/refuse)

群资料/设置

POST group/edit_info (修改群名/简介/公告)
POST group/update_settings (加入方式, 固定口令, 审核问题, 展示开关等)
POST group/reset_invite_code (重置邀请码)
POST group/transfer (转让群主)
POST group/disband (解散群组)
POST group/leave (退出群组)

💬 消息模块

发送群聊消息

POST route=message/send_group_msg
参数: room_id, content(文本), img(图片文件), reply_to, mention_uids(逗号分隔)

获取群聊消息

GET route=message/get_group_msg (room_id, before_id/after_id, limit)
返回 messages[] 包含 can_recall, is_essence, is_mentioned 等。

发送私聊消息

POST route=message/send_private_msg (friend_id, content, img, reply_to)

获取私聊消息

GET route=message/get_private_msg?friend_id=xx&last_id=xx (支持增量 last_id 和 before/after_id)
调用后自动标记对方发来的消息为已读。

语音消息

POST route=message/send_voice_msg (voice文件, duration, 和 room_id 或 friend_id)

撤回消息

POST route=message/recall_msg (msg_id, type=group/private, room_id当群聊必填)

标记已读

POST route=message/mark_read (friend_id 或 room_id + last_msg_id 可选)

GET route=message/get_mentions 获取 @和回复未读计数。

⭐ 精华消息

设置/取消精华

POST route=essence/set_essence (msg_id, room_id) 需要群管理权限，自动切换状态。

精华列表

GET route=essence/get_essence?room_id=xx → essence_list + can_remove

精华统计排行

GET route=essence/get_essence_stats?room_id=xx&type=today|week|month|all 返回总数、分类计数、贡献排行。

📢 举报 & 反馈

提交举报

POST route=report/submit_report
参数: type(user/group), uid/rid, reason(至少10字符), anonymous(0/1), 可选 target_name。

Bug反馈

POST route=bug_report (title, description)

🛠️ 工具上传（通用）

上传图片

POST route=utils/upload_image 字段 image → 返回 url

上传语音

POST route=utils/upload_voice 字段 voice → 返回 url

💡 提示：发送图片/语音消息时也可直接在发送消息接口中上传 img / voice，无需单独调用工具接口。

🛡️ 管理员接口（不对外开放）

⚠️ 以下接口仅供内部维护使用，第三方客户端无需调用，此处仅声明存在性，不提供参数及调用细节。
· 临时令牌生成 admin/generate_token
· 用户/群组封禁管理 admin/admin_ban
如需完整功能请使用普通用户/群主/管理员权限。

📌 第三方客户端开发建议

  • ✅ 登录成功后保持会话（Cookie 自动管理），后续请求携带即可。
  • ✅ 文件消息直接使用 send_group_msg / send_private_msg 的 img 字段，不必先调用工具上传。
  • ✅ 私聊增量同步：使用 get_private_msg 的 last_id 参数。
  • ✅ 群聊消息目前拉取全量，可自行缓存最后 ID 做本地增量。
  • ✅ 渲染时务必将 online_status, content, nickname 等字段转义，防止 XSS。
  • ✅ 所有 route 不带 .php 后缀，统一使用入口 /rpc/UniCsAC.php。
